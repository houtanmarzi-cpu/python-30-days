# پایتون به زبان آدمیزاد 🐍

## این ریپو چیست؟

اینجا دفتر تمرین من است برای یادگیری پایتون؛ **۳۰ روز، روزی یک ساعت، از صفر.**

هر روز یک موضوع کوچک یاد می‌گیرم، تمرینش می‌کنم و کدش را همین‌جا می‌گذارم. هیچ ادعایی نیست؛ فقط یک مسیر واقعی یادگیری، قدم‌به‌قدم و جلوی چشم همه.

## برنامه ۳۰ روزه

| هفته | موضوع | روزها |
|------|-------|-------|
| ۱ | مبانی | نصب، متغیر، شرط، حلقه، لیست، دیکشنری، پروژه حدس عدد ⭐ |
| ۲ | تابع و فایل | تابع، خطاها، کار با فایل، CSV، پروژه لیست کارها ⭐ |
| ۳ | کتابخانه‌ها | pip، requests، JSON، Pandas، نمودار، پروژه گزارش دما ⭐ |
| ۴ | پروژه نهایی | ایده، گیت، کد اصلی، تست، تمیزکاری، README، انتشار ⭐ |

## چطور اجرا کنم؟

```bash
python day-01/hello.py
```

فقط پایتون ۳ لازم است؛ هیچ کتابخانه اضافه‌ای برای هفته‌های اول نیست.
